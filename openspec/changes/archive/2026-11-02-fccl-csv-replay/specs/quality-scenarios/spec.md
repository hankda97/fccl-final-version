# Spec Delta

## MODIFIED Requirements

### Requirement: Q-02 What-if 固定比較區段

系統 SHALL 預設以最新已可見材料區段作比較對象；開始編輯後固定其原始設定、環境及識別，只能由使用者主動重選已可見區段更新基準，並使舊候選／結果失效。What-if 情境資料 MUST 與實測資料分離。回放推進及同區段晚到欄位不得改寫固定輸入；重啟後不可見的選區 MUST 失效，須主動重選，不自動恢復。

#### Scenario: 首次編輯固定最新可見區段
- **WHEN** 使用者在快照模式首次修改情境參數
- **THEN** 固定當時最新可見批號、材料區段、時間、原始製程設定及環境；之後改動只作用於情境副本

#### Scenario: 主動重選可見區段
- **WHEN** 使用者選擇另一已載入且可見的材料區段
- **THEN** 顯示新識別及原始上下文、候選值重設為新區段設定、舊預測／建議失效，來源 CSV 與實測 SPC 結果不變

#### Scenario: 回放持續與固定輸入分離
- **GIVEN** 已選可見區段並調整參數
- **WHEN** 回放新製程或同區段晚到品質／特徵
- **THEN** 目前監控仍更新，情境原設定、環境、識別及候選不變；更新基準只能主動使用當時可見輸入

#### Scenario: 重啟後明確失效
- **GIVEN** 情境區段因重新開始不再可見
- **WHEN** 繼續播放直至該區段再次可見
- **THEN** 不呈現失效情境的預測／建議或未來參數，不自動重選或恢復，明示須主動選擇後建立新比較
