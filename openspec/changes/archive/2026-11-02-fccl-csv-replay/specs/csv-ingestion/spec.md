# Spec Delta

## MODIFIED Requirements

### Requirement: DATA-02 驗證與功能適用性分離

系統 MUST 檢查必要欄位、時間、有限數值、物理範圍、缺值、重複與識別，回報 code、field、row、message；原值與空白／單位／排序正規化資訊 SHALL 可追溯。品質不足不妨礙可用預覽，候選輸入完整度不代表 SPC 適用或模型可推論；SPC 須另經逐目標子組／基準驗證，模型須逐目標檢查所需製程特徵及 Adapter 能力；其他有效目標不因局部缺資料停用。禁止補造量測、預測或猜單位／時區。回放適用性 SHALL 另檢查逐欄位／逐目標可信可得時間及來源時間 profile；載入成功或總標籤旗標不表示歷史當下可用。

#### Scenario: 部分品質未量測
- **WHEN** 有效識別與製程資料存在，但部分或全部品質欄位缺失
- **THEN** 缺品質欄保持缺欄、原有效資料可預覽，各品質／特徵／子組識別完整度分別回報，缺量測目標不生成 SPC 判定；Mock 預測只使用符合其特徵需求的製程資料，預測結果明確標為預測且不填回實測欄，其他目標依各自適用性提供 SPC 或預測

#### Scenario: 型別或物理範圍錯誤
- **WHEN** 時間無效、數值非有限、濕度超過 0～100、線速非正數，或列存在缺值／疑似重複
- **THEN** 指出來源列與原因，保留原始值供追溯，無效值不被替換為合法值；重複列保留供檢查但不計入候選有效輸入

#### Scenario: 時間來源不足但快照仍可檢查
- **GIVEN** 有效 CSV 缺發布時間或僅有 AVAILABILITY_ASSUMED
- **WHEN** 建立回放投影
- **THEN** 明示受限欄位／目標，不自動把事件或檢驗完成時間視為發布時間；有效快照及可靠通道仍可使用

#### Scenario: 回放預覽與驗證訊息防洩漏
- **GIVEN** 檔案含未播放列與其值層級問題
- **WHEN** 開啟正規化／原始預覽及問題清單
- **THEN** 只顯示已釋出欄位與可見問題；結構錯誤仍可先回報，未來值、品質分布與其問題統計不提前顯示
