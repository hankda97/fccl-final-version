# Spec Delta

## MODIFIED Requirements

### Requirement: SPC-04 模式一致性與規格分離

系統 MUST 以明確傳入的實測切片、固定基準與規則得到可重現結果，繪出子組均值、原始量測趨勢及 CL／UCL／LCL，與產品允收規格分開標示。情境資料不得改寫圖或基準；無效基準可顯示量測但不畫假界限。What-if 參數變更 MUST 不影響實測 SPC 狀態或事件；本案不交付播放控制。

#### Scenario: 相同前綴的計算接點比較
- **WHEN** 同一有界實測切片以相同基準／規則重算，切片以外未提供的資料被改動
- **THEN** 統計／界限／事件完全相同，不回讀全域 CSV 或未提供觀測；不以此測試宣稱 C7 真回放完成

#### Scenario: 測試替身改變情境參數
- **WHEN** What-if 狀態替身的線速或候選值改變
- **THEN** 相同實測切片的 SPC、基準版本及事件不變；真滑桿整合由本 Change 驗收

#### Scenario: 圖上來源與數值清楚
- **WHEN** 選擇任一有效連續目標
- **THEN** 圖上顯示目標／單位、子組時間、均值與量測點、CL／UCL／LCL 及異常標記；Mock／產品條件／基準版本可查，MD／TD 保留負值，規格不充作管制界限

#### Scenario: 基準無效或資料為空
- **WHEN** 無可用基準、無完整組或篩選結果為空
- **THEN** 顯示量測或空狀態及原因，不畫有效管制界限、不判定正常，也不阻擋資料檢查
