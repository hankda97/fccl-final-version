# Spec Delta

## Purpose

提供成員 C 已驗收的儀表板基礎工作空間，讓使用者在單一畫面載入及檢查 CSV、保留同工作階段的資料狀態，並清楚區分可用資料功能與尚未實作的監控、調參、圖表及回放占位。

## ADDED Requirements

### Requirement: WS-01 單一主畫面與原定功能配置

系統 SHALL 提供側欄 CSV／Mock 載入、產品與環境資訊，以及上方監控摘要、Alarm 區與 SPC、What-if、AI 圖表、資料檢查四個 Tabs。未實作的 SPC、預測、調參、Heatmap、SHAP 與回放 SHALL 明示占位，相關控制停用，不顯示偽造結果。

#### Scenario: 初次開啟與無資料畫面
- **WHEN** 首次開啟且沒有資料
- **THEN** 標題、側欄、上方監控及四個 Tabs 可辨識，品質值顯示「—」，Alarm 尚未判定，回放與解鎖停用

#### Scenario: 載入後功能可尋得
- **WHEN** 載入有效 C Mock
- **THEN** 資料檢查可用，原定 SPC／What-if／Heatmap／兩種 SHAP 顯示區仍可尋得且標示尚未實作，不宣稱已產生計算或建議

### Requirement: WS-02 分頁切換保留工作狀態

系統 MUST 在同一工作階段的重跑或 Tab 切換保留已載入資料、批號與時間篩選，不重新初始化業務狀態。只有成功載入不同資料／映射或實際改變篩選時 SHALL 清除舊資料相依的游標／情境接點；該接點不代表已實作回放或 What-if。

#### Scenario: 分頁切換與同源重載
- **WHEN** 已載入並篩選 CSV，切換 Tabs、重跑或載入相同來源／內容／映射
- **THEN** 資料、篩選與既有業務狀態保留；成功載入不同資料時才清除相依情境／游標，失敗嘗試不替換有效資料

### Requirement: WS-03 監控與情境來源標示

系統 SHALL 顯示目前載入來源、映射／Mock 設定版本與所選批號／時間及可取得的產品／環境資訊。模型未接入及情境未實作 MUST 明確提示，不以資料輸入完整度、占位指標或測試替身宣稱已有品質監控與預測。

#### Scenario: 資料可用但模型尚未接入
- **WHEN** 有效 CSV 已載入而正式或公式 Mock 模型皆未交付
- **THEN** 來源、產品與環境可查，模型顯示未接入，品質摘要及 Alarm 不顯示合格或零風險，未選區段提示保持清楚

### Requirement: WS-04 相依功能降級與機台邊界

系統 SHALL 在輸入不足時保留資料預覽與問題檢查，並明示 SPC／預測等尚未實作的狀態。所有既有顯示區與停用控制 MUST 標示模擬用途，不提供真實設備寫入或控制。

#### Scenario: 部分品質資料缺失
- **WHEN** CSV 有有效識別但部分品質或製程欄位缺失
- **THEN** 仍可預覽有效資料及問題／候選輸入完整度，不補造品質值，不把缺資料或未實作功能顯示為正常

#### Scenario: 檢視未實作的調參區
- **WHEN** 使用者檢視 What-if 與建議占位
- **THEN** 顯示模擬與未完成提示，解鎖停用，不提供任何真實機台控制動作
