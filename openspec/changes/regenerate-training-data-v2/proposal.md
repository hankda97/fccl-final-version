# Proposal：重新生成合成訓練資料 v2

## 目的

以 200 個獨立卷、約 20,000 個最終材料區段及約 80% 的區段聯合良率，提供足量 NG、穩定期與漂移期資料，支援品質模型、SPC 與未來模型比較。

## 範圍

- 重新生成七份合成 CSV，輸出至獨立 v2 目錄。
- 保留原始 `raw data` 作歷史追溯，不讓 v2 工作流自動讀取舊資料。
- 產生可重現 metadata、資料摘要、分割與漂移真值。
- 驗證數量、鍵值、時序、規格、良率、缺值語意及重跑一致性。

## 不包含

- 不以修改規格、隨機翻標籤或複製 NG 達成良率。
- 不將本次合成結果宣稱為真實產線良率或正式規格。
