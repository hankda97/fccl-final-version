# Spec Delta

## Purpose

定義可重現的 FCCL 測試線模擬時鐘、材料站別流動、參數事件及品質延遲，使使用者能在不連接真實設備的前提下觀察調參後的未來製程與品質反應。

## ADDED Requirements

### Requirement: TS-01 連續模擬時鐘與資料完整性

系統 SHALL 每 5 模擬秒產生一次製程訊號，且同一 Run 同時只能有一個 tick 執行；若運算落後 MUST 降低倍率或自動暫停，不得跳過、重複或並行補寫 tick。

#### Scenario: 正常連續運轉
- **WHEN** 使用者啟動 Run 且每次計算能在下一 tick 前完成
- **THEN** 訊號時間以 5 模擬秒等距遞增，序號唯一且資料順序可重現

#### Scenario: 運算速度不足
- **WHEN** 前一 tick 尚未完成而下一排程時間到達
- **THEN** 系統不啟動重疊 tick，並降低模擬倍率或暫停且顯示原因，不遺失資料

### Requirement: TS-02 站別材料流與延遲生效

系統 MUST 分別模擬塗佈、熟化與壓合站及材料區段位置；參數變更只影響尚未通過適用站別的材料，品質結果僅在區段完成三站及其品質延遲後可用。

#### Scenario: 變更不回寫過去材料
- **WHEN** 某材料已離開塗佈站後使用者改變塗佈間隙
- **THEN** 該材料與更早材料不受影響，尚未通過塗佈站的材料才使用新設定

#### Scenario: 品質尚未成熟
- **WHEN** 材料尚未完成三站或品質延遲尚未到期
- **THEN** 四項品質預測顯示未可得及預定可得條件，不使用未來訊號補值

### Requirement: TS-03 Setpoint、Actual 與參數事件

系統 SHALL 將設定值、模擬實際值及不可變參數事件分開保存；使用者以數字欄位提交一組候選值並確認後，系統 MUST 產生帶時間、站別、舊值、新值及適用材料邊界的事件。

#### Scenario: 套用有效參數
- **WHEN** 使用者提交位於 UI 操作範圍內的七項主要參數
- **THEN** 系統一次套用整組有效值、建立參數事件，並由後續 actual 訊號逐步反映，不把 setpoint 當量測值

#### Scenario: 任一欄位無效
- **WHEN** 候選組含非數值、缺值或超出 UI 操作範圍的欄位
- **THEN** 整組不得套用或建立部分事件，畫面逐欄顯示原因並保留目前設定

### Requirement: TS-04 固定可重現情境

系統 MUST 提供固定 seed 的穩定、厚度增厚、厚度變薄、溫度下降、風量衰減、壓力漂移及複合漂移情境；相同版本、seed、設定與事件序列 SHALL 產生相同模擬資料。

#### Scenario: 相同情境重跑
- **WHEN** 以相同版本、seed、配方及參數事件重跑同一情境
- **THEN** process signal、材料區段、品質及事件內容 hash 一致

#### Scenario: 情境真值隔離
- **WHEN** 漂移情境包含原因與開始區間真值
- **THEN** 真值只供驗證與稽核，不作線上模型特徵、SPC 量測或使用者調參建議輸入

### Requirement: TS-05 單一產品與配方邊界

初版 Run MUST 使用 `FCCL-DEMO-001` 與 `SIM-RECIPE-3.0`；產品規格、配方標準、UI 操作範圍、模型支援範圍及 SPC 界限 SHALL 分別標示與驗證，不得互相代替。

#### Scenario: 建立初版 Run
- **WHEN** 使用者建立新的測試線 Run
- **THEN** 系統顯示唯一支援的產品與配方、各參數單位及來源版本，並預載穩態連續線狀態

#### Scenario: 值在 UI 範圍但超出模型支援
- **WHEN** 候選值可操作但超出目前模型 manifest 支援範圍
- **THEN** 系統可拒絕正式品質推論或明示外插限制，不得把 UI 邊界宣稱為模型有效範圍
