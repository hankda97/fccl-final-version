# Spec Delta

## Purpose

定義測試線可控製程訊號的即時統計監控、固定基準、警報分級與復歸，使趨勢、失控及產品超規能在控制台被正確區分而不造成警報淹沒。

## ADDED Requirements

### Requirement: PSM-01 厚度 X-bar／R 監控

乾膠厚度 SHALL 以每個取樣時點五個橫向量測形成一個 X-bar／R 子組；系統 MUST 同時顯示子組平均、全距、固定中心線／界限及可判定狀態，不得把單點或品質預測冒充子組。

#### Scenario: 有效五點子組
- **WHEN** 同一材料位置取得五個有效且可追溯的橫向厚度量測
- **THEN** 系統新增一個 X-bar／R 子組並以固定 reference baseline 判定規則

#### Scenario: 子組不完整
- **WHEN** 少於五點、位置重複或任一必要量測無效
- **THEN** 該時點標示取樣不足且不納入 X-bar／R 規則，不以平均補成有效子組

### Requirement: PSM-02 連續訊號 I-MR／EWMA 監控

溫度、排風量、線速與壓合壓力 MUST 使用 I-MR 或 EWMA 的適用圖表與規則，不得標為 X-bar；首頁只顯示最多三張預設關鍵圖，其他訊號於詳細監控頁可查。

#### Scenario: 監控連續訊號
- **WHEN** 新的有效 actual 訊號抵達
- **THEN** 系統以增量方式更新該訊號的 I-MR／EWMA 狀態、最新 60 點與固定界限，不重算整個歷史 Run

#### Scenario: 首頁圖表數量
- **WHEN** 可監控訊號超過三項
- **THEN** 首頁仍只顯示三張關鍵圖，詳細頁提供其餘圖表與完整狀態

### Requirement: PSM-03 獨立固定基準與界限語意

製程 SPC baseline MUST 來自相同配方的獨立穩定 synthetic reference，不能由目前 Run 滾動估計；配方目標、產品規格及 SPC 管制界限 SHALL 分開呈現。

#### Scenario: 新 Run 啟動
- **WHEN** 新 Run 載入相容配方與 baseline
- **THEN** 整個 Run 使用相同基準版本，參數調整、漂移或重跑不重估中心線與界限

#### Scenario: 缺少相容基準
- **WHEN** 訊號或配方沒有相容且足量的穩定 reference
- **THEN** 系統顯示基準不可用並停止相依 SPC 判定，不以配方標準或產品規格取代管制界限

### Requirement: PSM-04 Alarm 分級與復歸

系統 SHALL 將狀態分為正常、警告、嚴重及證據不足，並區分製程失控與產品超規；參數提交不得立即清除 Alarm，只有後續有效量測符合復歸證據時才可結束事件群。

#### Scenario: 參數調整後尚無證據
- **WHEN** 使用者在異常期間修改參數但尚無足量後續有效點
- **THEN** 目前事件保持開啟並標示等待復歸證據，不顯示已恢復正常

#### Scenario: 後續證據達成復歸
- **WHEN** 後續有效點符合該規則預定的正常證據且沒有更嚴重規則
- **THEN** 事件群結束並保留開始、結束、影響點、規則與相關參數事件供查閱

### Requirement: PSM-05 有界摘要與可追溯明細

首頁 MUST 只顯示目前開啟事件及有界近期摘要；完整原始事件、界限、未四捨五入數值與來源 ID SHALL 在詳細頁或 Run 紀錄查閱，不能以大量紅色逐點事件淹沒操作區。

#### Scenario: 長時間漂移
- **WHEN** 同一訊號連續多點觸發相同或重疊規則
- **THEN** 首頁以一個事件群摘要顯示嚴重度、持續時間及影響點數，而非每點一張紅色卡片

#### Scenario: 查閱事件證據
- **WHEN** 使用者展開事件群
- **THEN** 系統提供其全部規則、量測、界限、時間與參數事件關聯，不更改原始判定
