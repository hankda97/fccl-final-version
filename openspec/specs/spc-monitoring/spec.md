# spc-monitoring Specification

## Purpose

為成員 C 的快照資料提供具來源與適用條件的 X-bar 品質監控，以獨立歷史 Mock 建立固定管制界限，讓有效實測異常可追溯且同步呈現；不把測試取樣假設、未接入模型或未實作回放視為正式產線能力。

## Requirements

### Requirement: SPC-01 明確合理子組與品質目標

系統 MUST 依已聲明的同次獨立試片、子組身分、固定大小及相容條件逐目標驗證，僅對完整有效子組計算抗剝離、尺寸 MD／TD、耐熱四個連續目標的均值與範圍。禁止以連續列數湊組、刪除壞列湊有效組或對外觀 0／1 標籤套 X-bar；無證據來源須標示不適用，不要求 A 採 C 欄位。

#### Scenario: C Mock 完整子組
- **WHEN** 同次獨立試片、子組識別、產品／批號／區段／時間及條件與設定大小一致，選定目標值皆有效
- **THEN** 產生可追溯的子組均值、範圍、樣本數及完成時間，不跨批次或條件拼湊

#### Scenario: 未完成或不可用子組
- **WHEN** 子組缺試片、重複試片、超過設定大小、混入條件／時間或有無效目標值
- **THEN** 該目標該組標為無效並中斷其連續規則，不刪列補組或產生 SPC 判定；其他完整目標可繼續

#### Scenario: 無子組依據或未知順序
- **WHEN** 來源無明確取樣／試片識別、條件設定，或無法確認相鄰子組及缺組界線
- **THEN** 說明受限項目，無合理子組不計 X-bar；無連續性證據不跨未知邊界累計趨勢，不改成 I-MR

#### Scenario: 部分品質與外觀標籤
- **WHEN** 耐熱度缺量測而其他連續目標完整，或選看外觀 NG
- **THEN** 耐熱度顯示缺資料，其他目標獨立驗證；外觀僅顯示實測有效數／NG 數及不適用 X-bar，沒有外觀管制界限或預測風險

#### Scenario: 篩選截斷子組
- **WHEN** 使用者時間篩選或外部傳入切片只含部分試片
- **THEN** 缺試片目標保持未完成，不回讀篩選外資料補齊；不修改側欄篩選或原始 CSV

### Requirement: SPC-02 獨立歷史基準與固定界限

系統 SHALL 使用監控起點之前、樣本不重疊的獨立歷史資料，逐目標驗證完整組數、非零組內變異、穩定性及產品／製程／單位／子組相容性，保存來源與版本。建立後 CL、UCL、LCL MUST 固定，不因篩選或監控值改變而重估；不適用時顯示「無法判定 SPC 狀態」與原因。

#### Scenario: 已知歷史資料的手算界限
- **WHEN** 同大小的完整歷史子組通過版本化 C Mock 穩定性與適用性檢查
- **THEN** CL 為歷史子組均值平均，界限為 CL ± A2(n) × 平均子組範圍，顯示來源、目標、單位、條件、組數、時間窗與版本

#### Scenario: 監控出現漂移或改變篩選
- **WHEN** 追加漂移觀測、切換批號或縮小時間範圍，產品與基準適用條件仍相同
- **THEN** 相同歷史／設定版本的 CL、UCL、LCL 完全不變，只重算選定資料的統計與事件

#### Scenario: 歷史不足或條件不符
- **WHEN** 歷史晚到／與監控樣本重疊、有效完整組不足、R-bar 為零、目標或條件缺失／不符、n 或常數版本不支援
- **THEN** 該目標不提供有效界限或正常判定，不從監控資料挑點補歷史；其他目標與 CSV 檢視繼續

#### Scenario: 歷史穩定性失敗
- **WHEN** 歷史均值或組內範圍違反已顯示版本的穩定性檢查
- **THEN** 列出失敗依據、拒絕該目標基準，不自動移除異常點重建或因檔名含 stable 而放行

#### Scenario: 新來源不能套用 Mock 基準
- **WHEN** 上傳檔案沒有已確認的取樣與基準適用來源設定
- **THEN** 仍可載入／預覽，SPC 顯示待確認；不只因欄名相同就自動套用 C Mock 基準或正式品質規則

### Requirement: SPC-03 可驗證的異常趨勢與 Alarm

系統 SHALL 依規則版本對有效相鄰子組逐目標偵測嚴格超界、六點嚴格單調與九點中心線同側，產生含來源、目標、規則、觸發組／時間、值與相關界限的唯一實測事件。無效／缺組／換批／條件變更中斷連續序列；重跑不得重複累加事件。

#### Scenario: 單點超界與界線相等
- **WHEN** 有效均值大於 UCL、低於 LCL 或恰等於任一界限
- **THEN** 前兩者觸發超界事件；等於界限不觸發此規則，所有事件以未四捨五入數值判定

#### Scenario: 已知趨勢序列
- **WHEN** 六個有效相鄰子組均值嚴格上升或下降
- **THEN** 第六點才產生趨勢事件，前五點無此事件；第七點仍符合時可產生該觸發組的新事件，但同組同規則只保留一個

#### Scenario: 九點同側與中心線相等
- **WHEN** 九個相鄰均值全部嚴格高於或低於 CL，或序列中有點恰等於 CL
- **THEN** 完整同側第九點才觸發；中心線點中斷同側序列，不計為任一側

#### Scenario: 相等、缺組或條件邊界
- **WHEN** 值相等、無效／缺組、批號／條件改變或子組時間間隔超過來源聲明
- **THEN** 相等值中斷嚴格趨勢，無效／缺組／邊界中斷所有連續規則；不先刪無效組再把兩側串接

#### Scenario: 同組多規則及重跑去重
- **WHEN** 同組同時符合多項規則，或同切片重跑、切 Tab、反覆選擇目標
- **THEN** 各規則各有可追溯事件，同來源／分析範圍／目標／規則／觸發組的結果一致，不重複附加，也不只計算畫面選中的目標

### Requirement: SPC-04 模式一致性與規格分離

系統 MUST 以明確傳入的實測切片、固定基準與規則得到可重現結果，繪出子組均值、原始量測趨勢及 CL／UCL／LCL，與產品允收規格分開標示。情境資料不得改寫圖或基準；無效基準可顯示量測但不畫假界限。What-if 參數變更 MUST 不影響實測 SPC 狀態或事件；回放 SHALL 逐目標只使用截至目前已可得的實測切片，保留相同固定基準與異常規則。

#### Scenario: 相同前綴的計算接點比較
- **WHEN** 同一有界實測切片以相同基準／規則重算，切片以外未提供的資料被改動
- **THEN** 統計／界限／事件完全相同，不回讀全域 CSV 或未提供觀測；實際播放控制另依 csv-replay 驗收，不以單一接點測試代替

#### Scenario: 測試替身改變情境參數
- **WHEN** What-if 狀態替身的線速或候選值改變
- **THEN** 相同實測切片的 SPC、基準版本及事件不變；既有滑桿及回放整合各依其情境驗收

#### Scenario: 圖上來源與數值清楚
- **WHEN** 選擇任一有效連續目標
- **THEN** 圖上顯示目標／單位、子組時間、均值與量測點、CL／UCL／LCL 及異常標記；Mock／產品條件／基準版本可查，MD／TD 保留負值，規格不充作管制界限

#### Scenario: 基準無效或資料為空
- **WHEN** 無可用基準、無完整組或篩選結果為空
- **THEN** 顯示量測或空狀態及原因，不畫有效管制界限、不判定正常，也不阻擋資料檢查

#### Scenario: 晚到量測與回放事件去重
- **GIVEN** 子組的各目標在不同時刻完成可得，且基準固定
- **WHEN** 回放逐步釋出、重跑及切換目標
- **THEN** 僅完整有效的目標子組可判定，缺組不被串接；相同來源／回放範圍／目標／規則／觸發組具有穩定事件身分，SPC Tab 與紅色 Alarm 同源、不重複，What-if 不影響結果
