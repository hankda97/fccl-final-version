# quality-scenarios Specification

## Purpose

讓成員 C 以可重現的示範預測完成固定材料區段的 What-if、模型風險與調參建議介面，同時保留實測資料及 SPC 的獨立性，並為正式模型留出可替換的轉接邊界。

## Requirements

### Requirement: Q-01 可重現且完整的 Mock 預測

系統 SHALL 提供與正式模型分離且標明公式／設定版本的確定性 Mock Adapter，對齊輸入識別及單位，輸出抗剝離度、尺寸 MD／TD、耐熱度、外觀 NG 預測與示範風險；相同輸入及版本 MUST 得到相同輸出，不得以測試真值或品質目標作為預測特徵，也不得在 C 重做 B 的模型訓練。

#### Scenario: 重跑及批次預測
- **WHEN** 同一輸入以單筆、批次或跨分頁重跑方式送入相同 Mock 版本
- **THEN** 同一識別的五項結果與單位一致，且不因呼叫順序改變

#### Scenario: 模型輸入不完整或輸出能力不足
- **WHEN** 必要製程特徵缺失／無效，或 Adapter 未提供所需目標
- **THEN** 對受影響區段回報不可用原因，不以零、缺值或舊結果代表正常預測，且其他有效資料檢視及 SPC 保持可用

### Requirement: Q-02 What-if 固定比較區段

系統 SHALL 預設以最新已可見材料區段作比較對象；開始編輯後固定其原始設定、環境及識別，只能由使用者主動重選已可見區段更新基準，並使舊候選／結果失效。What-if 情境資料 MUST 與實測資料分離。回放推進及同區段晚到欄位不得改寫固定輸入；重啟後不可見的選區 MUST 失效，須主動重選，不自動恢復。

#### Scenario: 首次編輯固定最新可見區段
- **WHEN** 使用者在快照模式首次修改情境參數
- **THEN** 固定當時最新可見批號、材料區段、時間、原始製程設定及環境；之後改動只作用於情境副本

#### Scenario: 主動重選可見區段
- **WHEN** 使用者選擇另一已載入且可見的材料區段
- **THEN** 顯示新識別及原始上下文、候選值重設為新區段設定、舊預測／建議失效，來源 CSV 與實測 SPC 結果不變

#### Scenario: 回放持續與固定輸入分離
- **GIVEN** 已選可見區段並調整參數
- **WHEN** 回放新製程或同區段晚到品質／特徵
- **THEN** 目前監控仍更新，情境原設定、環境、識別及候選不變；更新基準只能主動使用當時可見輸入

#### Scenario: 重啟後明確失效
- **GIVEN** 情境區段因重新開始不再可見
- **WHEN** 繼續播放直至該區段再次可見
- **THEN** 不呈現失效情境的預測／建議或未來參數，不自動重選或恢復，明示須主動選擇後建立新比較
### Requirement: Q-03 明確參數控制與模擬解鎖

系統 SHALL 預設提供線速滑桿，並以明確動作解鎖熟化及壓合情境參數；參數可用性與範圍 MUST 由 C 示範設定提供，未指定參數保持原值，解鎖不代表機台操作權限。

#### Scenario: 解鎖前後與無效輸入
- **WHEN** 使用者尚未解鎖進階參數，或候選值超出示範範圍／不是有效數值
- **THEN** 未解鎖參數不可編輯，無效候選不送入預測或建議；解鎖後只允許 allowlist 中的有效情境參數

### Requirement: Q-04 品質比較與可配置具體建議

系統 SHALL 對固定區段顯示五項目標的原設定與候選預測、差值及單位，並依版本化 C 測試規則呈現實際候選參數差值或無建議原因；模擬改善 MUST 標示為示範，不代表製程因果。正式允收、NG 門檻及多目標取捨依 TCP-004 整合，不由此 Mock 設定決定。

#### Scenario: 改善或惡化候選
- **WHEN** 可配置測試情境產生改善或惡化候選
- **THEN** 比較表呈現五項預測及正確差值；若測試策略選出候選，建議包含實際參數差值與單位（可驗證線速 −0.2 m/min 案例），並清楚標示模擬、版本及非因果保證

#### Scenario: 無合適候選或資訊不足
- **WHEN** 沒有候選符合目前測試規則，或必要模型／設定資訊不可用
- **THEN** 顯示無合適建議或無法評估及具體原因，不編造改善值；比較與建議區仍保留

### Requirement: Q-05 模型風險與不可用狀態

系統 SHALL 依可配置的 C 測試品質條件及外觀風險門檻標示預測 Alarm，明確區分目前監控預測與固定 What-if 風險；不可用狀態及原因 MUST 可見，且不得把示範風險宣稱為校準機率、實測 NG 或合格判定。

#### Scenario: 預測超規與外觀風險
- **WHEN** 可用預測依示範設定超出測試條件，或外觀示範風險達測試門檻
- **THEN** 紅色預測 Alarm 顯示目標、預測值／風險、適用條件、時間與區段；What-if 風險標明情境來源且不覆寫監控預測 Alarm 或 SPC Alarm

#### Scenario: 模型失效
- **WHEN** Adapter 不可用、必要輸出不受支援或部分特徵無法評估
- **THEN** 顯示模型來源、版本／能力及受影響目標的原因，不以缺預測表示正常，並保留 CSV 檢查與有效 SPC 功能
